# Руководство Translit

[← На главную](../README.md)

Tauri 2 для Windows x64: остановить одиночную игру, выбрать слово или выражение, перевести с контекстом и сохранить для изучения. Приложение рассчитано на разные игры. Интеграция проверялась на установленной Trails in the Sky 2nd Chapter (`sora_2nd.exe`, ремейк, DirectX 11).

## Запуск и управление

1. Запустите `Translit_0.2.0_x64-setup.exe`: установка для текущего пользователя включает WebView2, переводчик, грамматическую модель, OCR и их runtime. Системные Python / pip / Node.js не нужны. Portable-архив распаковывайте целиком; ему нужен WebView2, который устанавливает основной установщик.
2. Откройте игру и выберите её окно в приложении. Для оверлея используйте оконный режим / окно без рамки.
3. На реплике нажмите **F8** или **LB + RB**. Уже созданный оверлей показывается сразу, затем получает кадр и результаты OCR. Распознавание идёт в фоне; Escape / B снимают паузу и во время распознавания.
4. Выберите «Смысловые блоки», «Слова» или «Разбор». Фразу можно выделить протягиванием мыши либо Shift + клик. Карточка ограничена видимой частью монитора, её заголовок перетаскивается, длинное содержимое прокручивается под ним.
5. Проверьте перевод и разбор, поправьте их при необходимости, сохраните кнопкой или **Ctrl + Enter**.
6. **F8**, **Escape**, **B** либо «Продолжить» снимают паузу.

Геймпад через нативный XInput: **D-pad / левый стик** — фокус на слове или целом блоке в выбранном режиме, без нового запроса перевода; **LB / RB** — предыдущая / следующая фраза; **LT / RT / правый стик** — прокрутка карточки; **A** — открыть перевод; **X** — сохранить; **B** — продолжить; **Y** — переключить слова / блоки / разбор. На клавиатуре фразы переключаются **[ / ]**, карточка прокручивается **Page Up / Page Down**. Физические нажатия геймпада отдельно не проверялись. Вызов назначается на F1–F24, буквы, цифры, Numpad и сочетания Ctrl / Alt / Shift; для геймпада доступны кнопки, триггеры и комбинации. Центральная Xbox/Guide-кнопка недоступна через обычный публичный XInput; её можно переназначить в F8 средствами контроллера.

Главное окно открывается через системный трей. Собственный заголовок перетаскивается и содержит кнопки свернуть / развернуть / закрыть. Основная область прокручивается под заголовком, используется собственное оформление скроллбаров. Закрытие завершает Translit, снимает паузу, останавливает модель и отключает хуки.

## Модели, контекст и грамматика

Настройки → «Перевод, контекст и грамматика»:

| Вариант | Размер весов | Устройство | Назначение |
|---|---:|---|---|
| Офлайн | — | CPU | 57 076 словарных статей, словоформы, справочник выражений |
| **OPUS-MT EN → RU int8** | 75 MiB | CPU | Быстрый перевод реплики, основной вариант для слабого ПК |
| Qwen3.5 0.8B Q4_0 | 537 MiB | CPU | Свежий экспериментальный компактный разбор; грамматика может быть слабой |
| Qwen3.5 2B Q4_K_M | 1212 MiB | CPU | Экспериментальный разбор; в проверке допускал грамматические ошибки |
| Qwen3 4B Instruct 2507 Q4_K_M | 2382 MiB | CPU / GPU Vulkan | Более крупная модель для перевода, объяснений, грамматики и примеров |
| Ollama | ваша модель | ваш сервер | Локальный `/api/chat` |
| LM Studio / совместимый API | ваша модель | ваш сервер | `/v1/chat/completions` |
| OpenAI | выбранный ID | облако | Responses API и ваш ключ |

«Установить и использовать» скачивает выбранные веса и автономный runtime с проверкой SHA-256. OPUS-MT и небольшой английский синтаксический анализатор включены в дистрибутив; дополнительные Qwen скачиваются отдельно. Размер весов не равен расходу RAM / VRAM. Выберите CPU либо Vulkan, число потоков CPU и нажмите «Применить настройки». Авто использует половину доступных логических процессоров, максимум 8; ручной выбор ограничен доступными процессорами. Больше потоков может конкурировать с игрой.

**По умолчанию выбран OPUS-MT, включены установка при отсутствии и загрузка при старте приложения.** Сохранённый выбор модели, устройства и потоков применяется при следующем запуске. Установка / запуск идут в фоне; «Выгрузить» освобождает память. Если модель ещё загружается, первый перевод ожидает её готовности.

Vulkan использует выбранный runtime llama.cpp и первый доступный Vulkan-адаптер. При отсутствии адаптера выдаётся ошибка с предложением выбрать CPU: скрытого перехода на CPU нет. При отсутствующей регистрации установленного NVIDIA ICD приложение пробует обнаружить его manifest только для процесса модели, без изменения реестра Windows. Qwen3.5 в этом runtime ограничены CPU: проверка Vulkan дала некорректный текст. Для GPU предусмотрен Qwen3 4B.

OPUS-MT переводит реплику целиком и приблизительно выделяет выбранный фрагмент по attention-выравниванию. Грамматику отдельно разбирает локальная spaCy en_core_web_sm 3.8: части речи, подлежащее, объект, V1 / V2 / V3 / V-ing, формы известных неправильных глаголов. Её статистический разбор может ошибаться. OPUS сама объяснения не генерирует. Qwen / Ollama / API получают текущую реплику, предыдущий контекст и словарные подсказки, возвращают перевод, объяснение, грамматику и примеры. Модельный разбор может ошибаться; карточка позволяет редактировать его перед сохранением. Для отдельных известных оборотов (`butter … up`, `have a point`, `look forward to`) есть авторские грамматические заметки. Встроенные модели сохраняют эти заметки вместо догадок о таком обороте.

Контекст — текущая реплика и до 12 ранее **захваченных** реплик сессии. Приложение не читает все диалоги во время игры. История очищается при новом подключении. Блоки выделяются правилами по пунктуации, союзам, многословным статьям и выражениям. Это эвристика, фразу также можно выделить вручную.

В оверлее OPUS-MT сначала показывает быстрый перевод, а выбранный Qwen / внешний API затем уточняет значение и объяснение. Многострочный контекст переводится по строкам. Можно сохранить быстрый результат, пока подробный разбор ещё готовится; введённый вручную перевод не перезаписывается поздним ответом модели.

API ключ хранится в Windows Credential Manager. В облако отправляются текст и контекст, изображения не отправляются. После смены провайдера нажмите «Применить настройки».

## Изучение и хранение

Сохранённая запись содержит слово / выражение, перевод, оригинальный контекст, перевод реплики, объяснение, грамматику и примеры, если они получены. «Мой словарь» позволяет искать, редактировать, удалять и экспортировать JSON. Старые записи совместимы с новым форматом.

«Изучение» — карточки с раскрытием перевода и отметками «Помню» / «Ещё повторить». Управление: ← / → либо D-pad — карточка; A / Space — раскрыть; X — помню; Y — повторить. Число повторений и отметка изученного сохраняются. Отдельно сохраняется статистика обращений к словам / фразам, последние пять контекстов и встреченные конструкции. Из списка частых запросов можно создавать карточки с анализом, ситуацией употребления и примерами. Интервальное повторение: правильные ответы дают 1, 3, 7, 14, 30, 60, 120, 240 дней; ошибка — 10 минут и сброс серии. Есть очередь к повторению, все карточки и фильтр по игре. Даты и прогресс сохраняются.

- `%APPDATA%\local.translit.game-dictionary\vocabulary.json` — словарь и настройки.
- `models-v2\opus\` рядом с ним — OPUS-MT, spaCy, автономный Python runtime и журнал.
- `models-v2\` — GGUF модели, CPU / Vulkan runtime и журнал.
- `%TEMP%\translit-native-v2-<PID>\` — временный кадр и управление DLL.

## Игры и графика

- DLL x64 перехватывает DX11 Present / Present1 через MinHook и читает back buffer по запросу. Поддержаны BGRA/RGBA, MSAA resolve, R10G10B10A2. Для float HDR используйте SDR.
- «Авто» выбирает DLL для обнаруженного DX11 x64, для остальных — захват видимого клиентского окна Windows. DX9/12, Vulkan и 32-битные игры требуют отдельной проверки в оконном режиме. Режим захвата можно выбрать вручную.
- Интерфейс оверлея — отдельное окно Tauri/WebView2 над захваченным кадром. DLL не рисует интерфейс внутри swap chain. Эксклюзивный fullscreen не гарантируется.
- Основной OCR — английский Windows OCR; при недоступном языковом компоненте используется встроенный Tesseract 5.5.3 + eng. OCR может ошибаться на игровых шрифтах; строки из памяти движка не извлекаются.
- «Отключить» снимает паузу и отключает хуки. Повторное подключение к тому же процессу работает без перезапуска игры. DLL остаётся загруженной до выхода игры; detach здесь означает отключение перехвата.
- В режиме DLL пауза удерживает render / game loop на Present и продолжает обрабатывать Windows-сообщения, чтобы окно отвечало системе. Независимые потоки симуляции и звук могут продолжаться: это не универсальная пауза всех движков. Режим захвата экрана использует полную приостановку процесса; Windows может считать такое окно не отвечающим. Отдельный сторож возобновляет игру по команде, при выходе / сбое Translit либо через 15 минут.

## Сборка и проверки

Windows 10/11 x64, Rust MSVC, Node.js, CMake, Visual Studio Build Tools (C++, SDK с C++/WinRT), WebView2.

```powershell
npm install
npm run start
python scripts/prepare-runtime.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-ocr.ps1
npm run installer
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-portable.ps1
```

```powershell
npm run check
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/smoke-native.ps1
```

Подготовка дистрибутива требует Python и 7-Zip только на машине сборки. Для повторяемой сборки зависимости закреплены URL и SHA-256 в манифестах; `prepare-runtime.py` скачивает недостающие файлы.

Native-стенд запускает собственный DX11-процесс: инъекция, кадр, OCR, пауза, возобновление, восстановление после выхода родителя, detach и reconnect. Артефакты в `artifacts/`. Модельная проверка использует реальный локальный сервер, не заглушку. Облачные вызовы требуют настроенной модели / ключа.
